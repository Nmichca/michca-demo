# Michca Demo — Consulting Data/IA

App de démonstration avec deux agents :
- **Agent Discovery** : analyse de transcripts clients
- **Agent Veille** : synthèse de documents sectoriels

## Déploiement Vercel

1. Importe ce repo sur [vercel.com](https://vercel.com)
2. Ajoute la variable `ANTHROPIC_API_KEY`
3. Deploy !
